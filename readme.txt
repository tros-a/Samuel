Аппаратная часть
=================================================
Microcontroller ------------------------------CH582M
Display --------------------------------------OLED SH1106 128×64 SPI
USB connector USB-C --------------------------
2×AAA питание
5-позиционный джойстик
Сенсорная площадка DIT
Сенсорная площадка DAH
Разъём 3.5 мм TRS для внешнего paddle --------PJ-328
Выход на наушники-----------------------------PJ-328
TX выход через оптрон-------------------------PJ-328
SWD площадки для отладки и восстановления

===== OLED 1.3" SH1106 (I2C) =====

PB13  -> SCK
PB12  -> SDA

===== Джойстик =====

PB0   -> JOY_UP
PB1   -> JOY_DOWN
PB2   -> JOY_LEFT
PB3   -> JOY_RIGHT
PB4   -> JOY_ENTER

===== Внешний Paddle =====

PB5   -> DIT_IN
PB6   -> DAH_IN

===== Сенсорные площадки =====

PA5   -> TOUCH_DIT
PA14   -> TOUCH_DAH

===== Аудио =====

PB9   -> AUDIO_PWM

===== TX выход =====

PB10  -> TX_KEY_OUT

===== Детект штекера Paddle =====

PB11  -> PADDLE_DETECT

===== USB =====

USB_DP -> USB D+
USB_DM -> USB D-

===== SWD =====

SWDIO
SWCLK
RESET

===== Резерв =====

PB12
PB13
PB14
